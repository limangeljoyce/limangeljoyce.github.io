# Personal Portfolio

This is a simple personal portfolio built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page with sections: Home, About, Projects, Contact.
- `style.css` — core styles and layout.
- `mediaqueries.css` — responsive breakpoints.
- `script.js` — mobile nav toggle and smooth scrolling.
- `assets/` — place images or screenshots here.

## How to use

1. Open `index.html` in your browser to preview locally.
2. Edit the content: replace "Your Name", email and project links with your own.
3. Add project screenshots to the `assets/` folder and update the project cards in `index.html`.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In repository settings → Pages, choose the `main` branch and `/ (root)` folder.
3. Save — your site should be available at `https://<your-username>.github.io/<repo-name>` shortly.
